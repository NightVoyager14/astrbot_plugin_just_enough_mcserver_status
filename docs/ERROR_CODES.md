# 错误码

| 错误码 | 含义 | 常见原因 | 解决方案 |
| :--- | :--- | :--- | :--- |
| **SEC001** | 路径遍历拦截 | 路径中包含非法字符（如 `../`），可能导致越权访问插件工作目录之外的文件。 | Step 1：检查配置文件 `data\config\astrbot_plugin_just_enough_mcserver_status_config.json` 中 `info_card` → `background` → `upload` 项下的路径，确认是否包含 `..` 等特殊字符</br>Step 2：若该路径由你或你信任的工具写入，请删除该项并在 AstrBotUI 插件配置中重新设置</br>Step 3：如果 **你本人从未操作过该配置文件**，请注意：可能有人或程序/插件未经授权修改了配置文件，请检查近期日志，确认是否存在异常操作 |
| **RND003** | 信息卡片缓存文件清理失败 | 1. 缓存目录或文件权限配置错误，插件没有修改权限</br>2. 缓存目录被其他进程占用或锁定 | Step 1：检查插件图片缓存目录（`data\temp\JEMSSPlugin_temp_pics`）及其缓存文件的读写权限，确保 AstrBot 运行用户拥有完全控制权限</br>Step 2：确认无其他程序（如杀毒软件、资源管理器预览等）正在占用该目录下的缓存文件</br>Step 3：若问题持续，可手动删除 `data\temp\JEMSSPlugin_temp_pics` 目录下的缓存文件 |
| **NET001** | 服务器地址解析失败 | 1. 本地 DNS 解析服务异常</br>2. 网络连接不可用</br>3. 输入的地址格式不正确</br>4. 服务器域名已过期或发生变更 | Step 1：检查输入的服务器地址是否正确</br>Step 2：检查网络连接是否正常</br>Step 3：检查 DNS 解析服务或本地 hosts 文件是否正常 |
| **NET009** | 服务器信息获取失败 | 1. 服务器不在线或正在重启</br>2. 服务器已开启但被防火墙拦截</br>3. 该端口并非 Minecraft 服务</br>4. 网络连接不稳定或超时 | Step 1：检查输入的服务器地址及端口号是否正确</br>Step 2：确认所查询的服务器是否处于正常运行状态 |
| **CFG001** | 延迟阈值校验失败 | 延迟指示器的阈值不满足 `Excellent < Good < Medium < Bad` | 在插件配置中重新调整阈值 |
| **CFG002** | 配置导致无可见输出 | 配置中信息卡片渲染与文本信息输出均被禁用，从而导致插件无可见输出 | Step 1：如果你想要禁用该指令，你可以前往 AstrBotUI 中的 `插件` → `管理行为` → `指令` → `操作` 中直接禁用你想要禁用的指令</br>Step 2：如果这并非你的意图，请检查 AstrBotUI 中配置，以确保信息卡片渲染与文字信息输出至少有一个开启 |
| **CFG003** | 重复的服务器快捷名称 | 快捷查询中预设服务器快捷名称出现重复，这导致程序无法确定当前指令指向的预设服务器。因此程序会直接抛弃用户自定义配置而回退回默认配置 | 进入 AstrBotUI 的本插件配置页面中，删去或修改重复的预设服务器的快捷名称，保证预设服务器快捷名称无重复项 |
| **CFG004** | 重复的默认快捷服务器 | 快捷查询中的默认服务器出现重复 | 进入 AstrBotUI 的本插件配置页面中，修改默认服务器，保证默认预设服务器无重复 |
| **INP001** | 无效的快速名称 | 程序无法找到该输入的快捷名称或没有设置快捷灭你工程 | Step 2：若并非尝试以默认模式查询（即使用裸指令而不跟参数以查询默认预设服务器），请确认输入的快捷名称是否正确</br>Step 3：若无误，检查配置中预设服务器的快捷名称设置是否正确 |
| **INP002** | 非法的服务器地址 | 输入的服务器地址不符合规范 | 检查指令输入的服务器地址。如果使用的快捷查询则检查预设服务器配置的地址是否正确。</br>注：目前只支持ipv4和英文域名，暂不支持ipv6地址和中日韩等国际化域名 |
